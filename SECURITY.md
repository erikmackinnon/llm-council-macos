# Security Policy

## Supported Versions

The `main` branch is the only actively supported version for security fixes.

## Reporting a Vulnerability

Please use GitHub's private vulnerability reporting for this repository when available.

If private reporting is unavailable, open a minimal public issue without exploit details and ask maintainers for a private follow-up channel.

## Scope Notes

- Do not include personal credentials, provider session tokens, or private logs in reports.
- Provider website DOM breakage is usually a reliability issue, not a security issue, unless it creates privilege escalation or data disclosure risk.
